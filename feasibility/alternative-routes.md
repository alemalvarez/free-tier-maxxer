## Verdicts

- **Vercel bandwidth (Fast Data Transfer)**: NO KNOWN ROUTE on Hobby. Metric exists (`vercel.request.fdt_out_bytes`) but `/metrics/v1` and `/v2/observability/query` return 402 Observability Plus required (LIVE); undocumented `/v1/usage` is plan-gated; drains Pro+. Only fallback: parse threshold emails (coarse, undocumented thresholds).
- **Vercel edge/CDN requests**: NO KNOWN ROUTE (`vercel.request.count` -> 402, LIVE). APPROXIMATION at best: Web Analytics `pageviews` (JS-tracked views, excludes assets/API/bots; 50k events cap) — not comparable to the 1,000,000 CDN-request limit.
- **Vercel function invocations**: NO KNOWN ROUTE (`vercel.function_invocation.count` -> 402, LIVE). Email fallback only.
- **Vercel image optimization**: NO KNOWN ROUTE (`vercel.image_transformation.count` -> 402, LIVE). Email fallback only.
- **Supabase egress**: UNOFFICIAL ROUTE (`/platform/organizations/{slug}/usage[/daily]`, metric EGRESS with per-service breakdown; needs a dashboard session JWT, `sbp_` PAT rejected with 401 LIVE) + APPROXIMATION (`node_network_transmit_bytes_total` from the Prometheus endpoint = DB instance NIC bytes incl. replication/pooler traffic, excludes Storage/Auth/Functions/Realtime egress; Free availability contradictory and UNVERIFIED).
- **Supabase cached egress**: UNOFFICIAL ROUTE (same platform endpoint, metric CACHED_EGRESS). No approximation: no CDN-cache fields in logs or metrics.
- **Supabase realtime messages**: UNOFFICIAL ROUTE (platform endpoint, REALTIME_MESSAGE_COUNT / REALTIME_PEAK_CONNECTIONS). No approximation found (Prometheus only has `replication_realtime_lag_bytes`; no documented message-count log field).
- **Supabase edge function invocations**: UNOFFICIAL ROUTE (platform endpoint, FUNCTION_INVOCATIONS) + APPROXIMATION (`count(*)` over `function_edge_logs` via `/analytics/endpoints/logs`, max 24 h per query so the tool must accumulate daily; also yields approximate function egress from `response.headers.content_length`; needs `analytics_logs_read`, not verified LIVE; `functions.combined-stats` per function, shape UNVERIFIED).
